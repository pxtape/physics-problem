เพิ่มโจทย์ทีละไฟล์

  1. แปลงโจทย์เป็น LaTeX โดยใช้แม่แบบ templates/problem.tex
  2. ระบุ id, title, camp, topic, year, tags ใน comment ด้านบนไฟล์
  3. วางไฟล์ที่ content/camp-1/mechanics/CAMP1-MEC-001.tex หรือโฟลเดอร์อื่นภายใน content/
  4. Commit และ push เข้า main — GitHub Actions จะตรวจไฟล์และอัปเดตเว็บ

ปุ่มเพิ่มโจทย์ใช้ทดลองสมการ นำเข้าไฟล์ และบันทึกแบบร่างในเครื่อง การบันทึกแบบร่างไม่ส่งไฟล์ขึ้น GitHub
